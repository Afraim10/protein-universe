## Lessons for our production rules

The screenshot set is not uniformly two-tone: bright local accents, colored shadows, repeated shapes, and occasional broad transitions create considerable depth. Its consistency comes from **relationships**—foreground versus background, entity identity, contrast, scale, and purposeful repetition—not a fixed number of colors.

The original Protein Universe poster already uses those relationships: a broad flowing landscape counterbalances the ribbon hero, faint conformations recede, warm/cool regions organize discovery, and methods occupy a quieter strip. Later flat examples provide useful diagram layouts, but their heavier title/callout emphasis and more uniform cyan/violet masses should not become the default aesthetic.

Correct two opposite failure modes:

- **Excess modeling:** shiny identical beads, thick ambient shading, excessive highlights. Replace material effects with bounded colored planes while retaining topology and meaningful detail.
- **Excess flattening:** generic cyan lobes, two-tone stickers, isolated diagram on blank ground, every caption/part equally prominent. Restore contrasting color masses, hue variation, selective highlights and contextual depth while keeping dark breathing room.

Do not copy whole-poster palettes indiscriminately. Some supplied screenshots use bright local environments; the series keeps a dark overall field unless the user changes it. Do not add cute cell faces, stars, spacecraft, or patterned wallpaper merely because the broader studio uses playful motifs. The protein's actual architecture supplies the beauty.
