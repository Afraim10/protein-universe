# Contributing

Scientific corrections, clearer teaching captions, accessibility improvements and new poster proposals are welcome.

For corrections, identify the poster and exact region, explain the issue, and include a primary paper, PDB record or authoritative reference. Distinguish a scientific error from an intentional schematic simplification.

For a new poster, include the PNG, exact prompts, source links, review notes and known limitations. Label AI-assisted work and illustrative property maps. Do not include third-party commercial poster files or private data.

Keep file paths portable. Update catalog.json when adding or revising a poster. Contributions should state their attribution and licensing terms compatible with this collection.
