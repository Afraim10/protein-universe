## The story

I bought a physical hardcover Kurzgesagt artbook, which a friend brought from the United States to Egypt. Its illustrations stayed with me. Buying a collection of the studio's posters was outside my budget, so I began exploring how to create posters about the proteins and molecular processes that fascinate me.

Working with Codex and image generation, I developed a reusable workflow for choosing a scientific story, designing a consistent composition, consulting structural references, and iteratively reviewing the images. This repository shares the workflow and its outputs.

The visual inspiration is [Kurzgesagt — In a Nutshell](https://kurzgesagt.org/). This independent project is not affiliated with or endorsed by Kurzgesagt. A reusable AI skill does not reproduce the expertise and craft of their designers. Original Kurzgesagt poster images are not distributed here.

## What this contains

The skill is at `.agents/skills/artifact-template-protein-universe-posters/`. It includes instructions, visual references from this generated series, a design specification, and review guidance. It does not include an image model, API credentials, or free access to a generation service.

`posters/` contains selected PNGs and accompanying prompt/source records. `catalog.json` is a portable index for a future gallery website. The first four entries are the launch selection; the remaining posters form the wider collection.

## Scientific status

These are AI-assisted schematic illustrations, not coordinate-based molecular renders, experimentally validated figures, or calculated property maps. Generation-time checks caught and corrected some errors; they do not establish independent scientific validation. Consult each poster's notes before using it to teach. Corrections are welcome.

On 2026-10-28, all 11 downloads and matching skill references were replaced with the author-selected enhanced PNGs. Download paths remain stable. `catalog.json` records dimensions, byte sizes and SHA-256 checksums. These are raster enhancements, not vector masters or independently validated scientific figures. See each poster’s notes for version history and known issues.
